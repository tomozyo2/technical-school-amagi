## 本編

   - 大将「あの11番の震え…ただの寒がりではない。力をためているのだ！」
   - 手下(14)「た、たしかに！さっきより震えてます！」
2. ペンギンボールで試合再開。審判が笛「ピッ」。大将がボール1個を足元に置いて号令。
   - 大将「ボールは俺が運ぶ！手下は全員、11番を囲め！」
   - 手下たち「ははーっ！」
3. ぷるぷる丸のまわりを、手下ペンギン6〜7匹が輪になって囲み、じーっと見つめる。ぷるぷる丸の震えがMAX。

   - 手下「震えが強くなった！」「な、何か来るぞ…！」（手下たちのほうが一歩下がる）
4. 輪から遠く離れた場所で、メロがひとりぽつん。まわりに誰もいない。手を上げてアピール。

### 3枚目（⑨〜⑫）

    - ぷるぷる丸「…みんな、寒いの？だいじょうぶ？」

    - 右下に「49話へ続く」（文字だけ）

## オチ／引き
オチ：みんながぷるぷる丸の震えをまねした結果、会場じゅうが震えだして、いちばんのビビリのぷるぷる丸だけが落ち着いてしまう「立場の逆転」。ぷるぷる丸がみんなを心配する側になるのがポイント。
引き：大将は「震えが止まった＝本気モード」とさらに勘違い。ボールはぷるぷる丸の足元、スコアは犬1-0ペンギンのまま。49話は「本気（と思われている）ぷるぷる丸」がボールをどうするか、から始められる。

## 既存の48話「ペンギンすべる」との違い
- 既存：47話の「警戒」はやらず、ペンギンの滑りの連携で1-1に追いつかれ、犬チームがのんきに笑うオチ。
- 別案：47話の引き（ペンギンが勘違いして警戒）を正面から使い、「勘違いがどんどん広がる」話。点は動かず1-0のまま。主役はぷるぷる丸＋メロ（やきもち）で、オチは「ビビリだけが落ち着く逆転」。

## 未確認の点（社長に確認したいこと）
1. 既存48話を作ったときに「ぷるぷる丸に全員マーク」の案は不採用になっている。今回は読み比べ用なので、あえて③で「全員で囲む」を使った。気になるなら、③は「手下3匹で囲む」くらいに弱められる。
2. ⑪⑫で、ぷるぷる丸が「このコマだけ震えが止まる」。固定設定は「いつも震えている」なので、1回だけの例外として使ってよいか。（設定は変えない）
3. 44話コマ11に「ミトンの震えが円陣に伝わる」ギャグがある。今回は「わざとまねして広がる」なので別ものだが、似ていると感じるかどうか。
4. ⑫で冷静なウサギの審判まで震える。キャラが崩れすぎないか（セリフなし・小さくにしてある）。
5. この案を採用する場合、49話は「ぷるぷる丸がボールを持った状態」から始まる。既存48話の流れ（1-1）とは49話がまったく変わる。
