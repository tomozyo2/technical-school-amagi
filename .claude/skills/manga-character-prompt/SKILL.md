### ルール
1. 名前と見た目の組み合わせは上の表が正。台本やプロンプトを作る前に、「誰が何をするか」を表と照らして、取り違えがないか確認する（特にチロ＝キャメル、メロ＝オレンジ、レオ＝灰黒に白い一房、ニャーランド＝金髪ポニーテール）。
2. プロンプトには、出てくるキャラの固定設定をそのまま入れる。自分で言い換えたり省略したりしない。名前だけ書いて設定を省くのも禁止。
3. 新キャラが出たら、その場で次を決めて、この表と固定設定に追加する：名前／種類／チーム／見分けポイント／性格／口ぐせ／初登場話。名前が未定なら「（仮）」を付けて、ユーザーに確認する。
4. 三面図（正面・側面・背面）などの参考画像をもらったら、見た目の特徴をテキストにして固定設定へ反映する。
5. 固定設定を変えるときは、必ずユーザーに確認してから変える（勝手に変えない）。変えたら、story-archive.md の「記録の信頼度」の注意書きも合わせて直す。
6. 台本の中で新しい性格・クセ（例：犬キーパーはネコ嫌い）が決まったら、「性格・口ぐせ」欄に追記する。

7. 「未確定キャラ」は、名前・見た目・性格をまだ固定扱いしない。新しい設定を勝手に足さず、使う話ではプロンプトに「（仮設定）」と書く。確定の連絡をもらったら、この表と固定設定を更新する。

## 画像全体のサイズ・縦横比（固定・2026-09-22決定）
新しい話をChatGPTに作ってもらうときは、コマがすべて入った「1枚の絵全体」のサイズを、毎回必ず次で統一する。
```
縦横比2:3、1024×1536（縦長のイラスト）
```
- 理由：過去の話には、2:3のものと4:5（1080×1350）のものが混ざっていて揃っていない（さらに11話は9:16という失敗もあった）。今後はこれで統一し、社長やAI社長にその都度確認しなくても、いつもこのサイズでお願いしてよい。
- 過去に作った話の画像はそのまま（描き直さない）。
- コマの向きは「2列に並べる横長のコマ」にすると、あとでインスタグラム用に切り分けたときに大きく見えることを確認済み（2026-09-22・詳しくは `claude code専用\リサーチ\2026-09-21_漫画を1コマずつ表示する提案.md` 参照）。新しい話のコマ割りは、できるだけこの2列レイアウトにする。

## 話数の管理（1話〜最新話）
- 全話のストーリー・コマ台本・オチは同じフォルダの `story-archive.md` にまとめてある。「○話のストーリー／プロンプト」と言われたら、まずこれを読む。
- 新しい話を作ったら、必ず `story-archive.md` に追記する（漫画ファイルは manga/ フォルダ）。
- 新しい話を考える前に、直近の話のオチを確認し、同じ型（例：必殺技→ノーゴール）が続かないようにする。

## プロンプトの作り方（過去話の呼び出し・再作成も同じ）
ChatGPTに1回でコピペできるよう、1つのコードブロックにまとめる。中身は次の順番：
1. 【画像全体のサイズ】（上記「画像全体のサイズ・縦横比」の指定＝縦横比2:3、1024×1536。毎回必ず入れる。聞き直さない）
2. 【絵柄スタイル】（上記の共通スタイル）
3. 【登場キャラ設定】（その話に出るキャラだけ。上記の固定設定をそのまま使う。脇役は「ネコチームの他の選手たち：色んな色のネコキャラ、青チームのユニフォーム」のように一言で）

4. **【タイトル帯】（2026-09-24決定・毎回例外なく必ず入れる）**
画面いちばん上に「〇話 タイトル」（例：「10話 天然ライバル」）を入れる指示を必ず書く。デザインは太めの丸ゴシック体・白フチ＋オレンジ〜黄色のグラデーション、左右に肉球マークの飾り、背景は青空と薄い雲の横長の帯（過去話と同じデザイン）。話にタイトルがまだ決まっていない場合は、先に社長に確認してから作る（タイトルなしで進めない）。

5. 【1コマ目】〜【Nコマ目】（story-archive.md のコマ台本を、絵が浮かぶ文章にして、セリフは「」で残す。ふきだしの中に話者の名前は書かない）

**最終コマには、必ず「（次の話数）話へ続く」の文字を画面右下に入れる指示を書く（2026-09-24決定・毎回例外なし）。**
「この話は一区切りだから入れない」といった判断は台本担当・漫画担当ともに行わない。話のオチがどう終わろうと、次の話数が存在する限り必ず入れる（最新話の場合も、次に来る話数を仮に入れておく）。過去に「10話で一区切りだから」と省いてしまい、社長から必ず入れるよう指摘を受けたため、この判断の余地自体をなくす。
プロンプトと一緒に、基準画像 `manga\6匹の仲間たち_キャラ設定.png` をChatGPTに添付する（「添付の三面図と同じ見た目で描いて」と一文添える）。

## プロンプトは短く・ChatGPTの生成回数を節約する（2026-09-24決定）
ChatGPTの画像生成には回数制限があるので、プロンプトはなるべく短く、少ない指示で済ませる（例：直したいコマ1つだけを直す・「他は変更しない」の一文で済ませる）。
**ただし、細かく表現しないと意図どおりに描けない場合（吹っ飛び感などの迫力、微妙な表情・ポーズ、位置関係など）は、この節約はなしとする。** 1回で当てるほうが回数の節約になるので、その場合は細かく書いてよい。

## 使い方
0. **この漫画のストーリーを考える・依頼されたときは、必ず先に漫画担当エージェント（manga-manager）を起動する**（社長の決定）。話の案づくり、オチの相談、続きの展開、過去話の確認すべてが対象。自分だけで案を出さない。
1. ユーザーから話数・コマ割り（誰が何をする）を聞き、日本語で台本としてまとめる（1コマ = 1つの出来事）。
2. 台本が確定したら、ChatGPT（画像生成）にそのまま貼れる日本語プロンプトをコマごとに作る。
   - 各プロンプトの先頭には必ず「絵柄スタイル」＋登場するキャラの設定文（上記から該当キャラのみ）を付ける。
   - 新キャラが出てくる話では、その回だけの見た目説明を追加してよいが、チロ・メロ・レオ・審判の基本設定は変えない。
3. 台本・プロンプトを提示したら、ファイル保存や画像生成の実行はせず、まずユーザーに確認する（勝手に進めない）。
4. 新しい話数ファイルを作る前に、manga/フォルダの既存ファイル名を確認し、話数が重複していないか確認する（すでに同じ番号のファイルがあれば先にユーザーに確認する）。
