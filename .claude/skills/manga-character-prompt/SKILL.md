### ルール
1. 名前と見た目の組み合わせは上の表が正。台本やプロンプトの前に「誰が何をするか」を表と照らして、取り違えがないか確認する（チロ＝キャメル、メロ＝オレンジ、レオ＝灰黒に白い一房、ニャーランド＝金髪ポニーテール、ロナド＝茶色ツンツン髪のダルメシアン）。
2. 出てくるキャラの見た目は、固定設定から外さない。名前だけ書いて設定を省くのは禁止（短縮版でも、見分けポイントは必ず入れる）。
3. 新キャラが出たら、その場で「名前／種類／チーム／見分けポイント／性格／口ぐせ／初登場話」を決めて、この表と固定設定に追加する。名前が未定なら「（仮）」を付けて社長に確認する。
4. 三面図などの参考画像をもらったら、見た目の特徴をテキストにして固定設定へ反映する。
5. 固定設定を変えるときは、必ず社長に確認してから変える（勝手に変えない）。
6. 台本で新しい性格・クセが決まったら、「性格・口ぐせ」欄に追記する。
7. 「未確定キャラ」は固定扱いしない。使う話ではプロンプトに「（仮設定）」と書く。確定したら表と固定設定を更新する。

## プロンプトの作り方（過去話の呼び出し・再作成も同じ）
**今の手本は `60話_プロンプト.md`（短縮版）。** 長いと無料ChatGPTがエラーになるので、三面図を添付する前提で短くする。1回でコピペできるよう、コードブロックにまとめる。

中身の順番：
1. 三面図の添付一文／縦横比2:3・1024×1536／白い余白・黒い枠線・2列×2段／コマ番号は描かない・ふきだしは枠からはみ出させない・話者名は書かない／絵柄スタイル
2. **タイトル帯（1枚目の本編にだけ）**：画面いちばん上に「〇話　タイトル」。太めの丸ゴシック体・白フチ＋オレンジ〜黄色のグラデーション、左右に肉球マーク、青空と薄い雲の横長の帯。タイトル未決なら先に社長に確認（タイトルなしで進めない）。2枚目以降は「タイトル帯なし」。
3. 登場キャラ（その枚に出るキャラだけ。見分けポイントは必ず入れる）
4. 各コマの場面とセリフ（「」で残す）
5. **最後の1枚の最後のコマには、画面右下に「（次の話数）話へ続く」の文字**を入れる（毎回例外なし・最新話も次の話数を入れる）。

**表紙プロンプトも必ずセットで作る**：Instagramカルーセル1枚目＆サイト1ページ目用。サイズ・絵柄・三面図添付は本編と同じ。場面は毎回自由（目を引く楽しい一場面）。必須は画面いちばん上に「〇話　タイトル」を同じデザインで大きく入れること。本編と表紙の両方を社長に提示する。

**生成回数の節約**：プロンプトはなるべく短く。直すときは「直すコマだけ・他は変更しない」。ただし迫力・微妙な表情・位置関係など、細かく書かないと当たらない場面は、細かく書いてよい（1回で当てるほうが節約）。

## 使い方
0. **漫画のストーリーを考える・依頼されたときは、必ず先に漫画担当（manga-manager）を起動する**（社長の決定）。案づくり、オチの相談、続き、過去話の確認すべて。自分だけで案を出さない。
1. 社長から話数・コマ割りを聞き、日本語で台本にまとめる（1コマ＝1つの出来事）。
2. **台本→社長OK→プロンプト**の順。台本のOKが出るまでプロンプトは作らない。
3. 台本・プロンプトを出したら、ファイル保存や画像生成は実行せず、まず社長に確認する。
4. 新しい話数ファイルを作る前に、manga/ の既存ファイル名で話数が重複していないか確認する（あれば先に社長に確認）。
