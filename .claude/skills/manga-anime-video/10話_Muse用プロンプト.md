## 【試し1】原作コマを添付して動かす

添付：10話の漫画画像（できれば1コマずつ切ったもの。無理なら全体の1枚）

```
添付した4コママンガ（チロ・メロ・レオの3匹だけ）を、そのままの絵柄で動く短いアニメにしてください。
・縦長（9:16）、全部で20〜30秒、コマの順番どおりに8カット。
・絵柄・色・キャラの顔を変えない。新しいキャラは足さない。
・動きは小さく：まばたき、耳としっぽのゆれ、口パク、ふきだしのポップアップ程度でOK。
・最後のカットは3匹が笑ってわちゃわちゃして終わり（「続く」表記なし）。
・まず1カット目だけ作って見せてください。問題なければ続きを作ります。
```

## 【試し2】文章だけで作る（テキスト→動画）

```
かわいいちびキャラ風の日本の子供向けサッカー漫画アニメ（太い線、パステルカラー、明るい色）。縦長9:16、全部で約25秒、8カット。
舞台は昼間のサッカー場。出てくるのは3匹だけ。他のキャラは出さない。

【キャラ（毎カット同じ見た目）】
・チロ：キャメル色のふわふわの犬。丸い垂れ耳、大きな垂れ目で涙目がち、ハートのペンダント、赤いユニフォーム背番号10。甘えん坊。
・メロ：オレンジ色のキツネ耳（尖った耳）の犬。小さくてまんまる、不敵な表情、黒い数珠玉に青と金の鈴の首輪、赤いユニフォーム背番号9。熱血で元気。
・レオ：グレー黒のサバトラ柄のネコ。頭に白い毛の一房、青いユニフォーム背番号10。クールだが、うっかり天然。

【カットと動き】
1. 茂みからボールを抱えて出てくるレオ。体に土と葉っぱがついている。気まずそうに咳払い。字幕「…ゴホン。さっきは助かった」
2. レオが姿勢を正し、いつものクールな顔に戻る。字幕「まだちゃんと名乗ってなかったな。俺の名前は『レオ』だ！」
3. メロが元気にジャンプして「よろしくレオ！」。隣でチロが笑顔でうなずく。
4. レオがボールを地面にセットし、ドヤ顔。字幕「今度こそ挽回だ。俺の必殺カーブシュートを見せてやるよ」
5. レオが助走して、気合十分の顔でシュート。字幕「必殺カーブシュートォォ！！」
6. ボールがまっすぐ飛んでいく（曲がらない）。メロが目を丸くして「曲がらんのかい！」、チロも驚く。
7. レオが自分のシュートを見て真顔でフリーズ、冷や汗タラリ。字幕「…あれ、曲げるの忘れた」
8. チロとメロが大笑い。レオはしっぽを丸めて赤面、耳をぺたんと伏せて「べ、別に大したことじゃ…」。3匹がわちゃわちゃする明るい終わり。

【お願い】
・ボールは1カットに1個。ゴールは出さない。
・キャラの見た目をカットごとに変えない（特にチロの丸い垂れ耳とメロの尖ったオレンジの耳を取り違えない）。
・セリフは字幕で出す（声はなくてよい。出せるなら、チロは高くてかわいい声、メロは元気な声、レオは落ち着いた声）。
・長さや回数の制限で全部作れない場合は、1〜4カット目と5〜8カット目の2本に分けてください。
```

## 続けて頼むとき（Museへの追加お願いの例）
- 「GIFにも変換して」（GIF変換は成功例あり）
- 「キャラの顔が崩れたカットだけ作り直して」
- 「2本に分けた場合、つなげて1本にして」

- どちらの方式が通ったか、長さ・回数の上限を、社長が教えてくれたらここに追記する。
