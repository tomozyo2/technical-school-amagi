# 漫画 → 声つき動画（動く漫画）

1話（2026-10-20）で作ったやり方。インスタ用カルーセル画像を材料に、コマを横から入れ、カメラで寄ったり揺らしたりして、キャラの声・字幕・効果音をつける。

## 声のルール（いちばん大事）

- **キャラの声は [voices.json](voices.json) で固定。** 声の種類(voice)・速さ(speed)・高さ(pitch)・名札の色(color)。
- 社長OK済み（2026-10-20）：チロ・メロ・審判・キーパー・ナレーション・ネコ（名前なしの青チームのネコ。4話で決定）・イヌばやしくん（キーパーと同じ声。6話で決定）。**勝手に変えない。** 変えるときは社長に試聴してもらってから。
- 新キャラ（レオ・ニャーランドなど）が初めてしゃべる回は、声を決める → 試聴ファイルを社長に聞いてもらう → OKで voices.json に書く。レオの設定は仮。
- 2026-10-25：「機械っぽい」と言われ、高さの加工を rubberband に変えた版（`漫画アニメ動画\声のお試し\`）と VOICEVOX への乗りかえを提案したが、社長の判断で**今のままにした**。また言われたら、この2案から出す。
- 声の道具は無料のKokoro（パソコンの中だけで動く）。日本語の声は jf_alpha / jf_gongitsune / jf_nezumi / jf_tebukuro / jm_kumo の5種類だけ。高さ(pitch)でキャラの差を出す。
- **セリフには必ず「yomi（ひらがなの読み）」を書く。** 漢字のままだと読み間違える（例：「第1話」の「話」を「はなし」と読む）。小さい「ぁ」は読まれないので「あ」にする（「ぱすだぁぁ」→ yomi「ぱすだあああ！」）。

## 置き場所

- 動画プロジェクト：`C:\Users\tomoz\Desktop\AI作業場\漫画アニメ動画\<N>話\`（**サイトのフォルダには入れない**。GitHubに大きいファイルが行ってしまうため）
- 材料：`テクニカルスクール甘木サイト\manga\インスタ用カルーセル\<N>話\01.jpg〜`（01＝表紙、02〜＝コマ）。カルーセルが無い話は先に manga-instagram-carousel スキルで作る。
- Python：`%USERPROFILE%\.claude\kokoro-venv\Scripts\python.exe`（声・画像の道具入り）。以下 `$PY` と書く。スクリプトは `$PY` で動かし、`PYTHONIOENCODING=utf-8` をつける。

## 手順（確認 → 実行 の順を守る）

1. **台本を社長に確認。** 漫画のセリフを読み取り、「誰が・何を言うか」の割り振りを箇条書きで見せてOKをもらう。名前つきキャラの名前は manga-character-prompt スキルの見分け表に合わせる。
2. **プロジェクトを作る**（Git Bash）：
   ```bash
   cd "C:/Users/tomoz/Desktop/AI作業場/漫画アニメ動画"
   npx hyperframes init "<N>話" --non-interactive --example=blank --skill=general-video
   ```
3. **材料をそろえる**：
   ```bash
   $PY <このスキル>/scripts/crop_panels.py "<カルーセルの<N>話フォルダ>" "<プロジェクト>/assets"
   ```
   さらに、1話のプロジェクト(`漫画アニメ動画\1話\assets\`)から `MPLUSRounded1c-ExtraBold.ttf`（丸い文字）・`icon.jpg`（つづく画面のアイコン）・`sfx\`（効果音）をコピーする。
4. **lines.json（セリフ一覧）を書く** → 声を作る：
   ```json
   [{ "id": "p1_chiro", "chara": "チロ", "text": "ぱすだぁぁ", "yomi": "ぱすだあああ！" }]
   ```
   ```bash
   $PY <このスキル>/scripts/make_voices.py lines.json assets/voice
   ```
   `chara` は voices.json にある名前だけ。表紙のタイトル読み上げは `"chara": "ナレーション"`。
5. **episode.json（動画の台本）を書く** → index.html を作る：
   ```bash
   $PY <このスキル>/scripts/build_episode.py .
   ```
   時間は声の長さから自動計算。書き方は下の「episode.json の書き方」。1話の `漫画アニメ動画\1話\episode.json` がお手本。
6. **チェック**：`npx hyperframes check`（「Check passed」ならOK。nested_structure / timeline_track_too_dense の注意は無視してよい）。`npx hyperframes snapshot --at <秒,秒,...>` で場面の写真を撮り、ふきだしが切れていないか・字幕がはみ出していないか自分の目で確認。
7. **社長に見てもらう**：`npx hyperframes preview` で編集画面（Studio）を開く。
8. **社長OKのあとで動画ファイルに書き出す**：`npx hyperframes render` → できたMP4の場所を伝える。

## episode.json の書き方

```json
{
  "series": "チロんぽ＆メロんぽ", "title": "第1話", "handle": "@chiromero_fc",
  "end_text": "つづく…", "follow_text": "フォローしてね！",
  "scenes": [
    { "type": "cover", "image": "cover.jpg", "sfx": ["sparkle"], "beats": [{ "line": "title" }] },
    { "image": "panel1.jpg", "cam0": [1, 0.5, 0.5],
      "beats": [{ "sfx": ["pop"], "cam": [1.1, 0.38, 0.45], "line": "p1_chiro" }], "tail": 0.3 }
  ]
}
```

- `scenes`：表紙(`"type":"cover"`)とコマを順番に。最後に「つづく」画面が自動でつく。
- `cam0` / `cam` / `cam_end`：カメラ `[拡大率, 横の位置, 縦の位置]`。位置は絵の左上が0・右下が1。`[1, 0.5, 0.5]`＝全体。`[1.6, 0.2, 0.45]`＝左のキャラに大きく寄る。
- `beats`：コマの中の出来事を順番に。`line`＝セリフのid、`cam`＝そこへカメラを動かす、`camDur`＝動かす時間、`sfx`＝効果音、`shake`＝画面ゆれ、`pop`＝ポンッと弾む、`hold`/`pause`＝間をあける秒数。
- `tail`：コマの最後の余韻（秒）。
- 効果音（assets/sfx）：whoosh-short（コマ切り替え・自動）、pop、impact-bass-1（キック）、sparkle、chime（ゴール）、whistle（審判の笛）。
- 3人以上しゃべるコマは、話す人へ順番にカメラを動かす（1話の4コマ目がお手本）。
- **横長のコマ**（4話など8コマの話）は自動で「縦に広い窓（1000×760）＋横スライド」になる。絵の約7割しか映らないので、拡大率は1.0〜1.1にして、横の位置（0.25＝左の人、0.75＝右の人）でしゃべる人を映す。ふきだしが窓の端で切れやすいので、必ず写真で確認する。4話の `episode.json` がお手本。窓の高さは episode.json の `"landscape_h"` で変えられる。
- 横長のコマは元の絵が小さい（約680×370）ので、少しボヤける。

## 切り抜き方式（キャラ自身を動かす「アニメ」版）

2話・3話（2026-10-25、社長OK）で作ったやり方。上の方式は「止まった絵にカメラを寄せる」だけだが、こちらは絵をキャラ・ボール・ふきだし・文字の部品に分けて、それぞれ動かす。社長が「アニメーションじゃなくてアニメがいい」と言ったらこちら。お手本は `漫画アニメ動画\2話_切り抜き版\` と `3話_切り抜き版\`（`index.html` と `tools\prep_all.py`）。

- **置き場所**：`漫画アニメ動画\<N>話_切り抜き版\`（前の版は残す）。材料は前の版の `assets\`（panel1〜4.jpg・cover.jpg・icon.jpg・voice\・sfx\・フォント）をコピー。声は前の版で作った `voice\` をそのまま使う。
- **部品づくり**：[scripts/cutout_template.py](scripts/cutout_template.py) を `tools\prep_all.py` にコピーし、コマごとに `grab(img, (x0,y0,x1,y1))`（四角で囲んで色で切り分け）・`bubble()`（ふきだし）・`ellipse()`（小さいボールや汗）で部品を指定する。座標は panel<N>.jpg の元の大きさ（高さ1152）。実行すると確認画像（ピンクの上の部品＋背景）ができるので、必ず目で見る。
  - `npx hyperframes remove-background` は人間用で、犬・キツネのキャラは抜けない。使わない。
  - 離れた文字（「ドュオォン」など）は `keep_frac=0.15` をつけないと1文字しか残らない。
  - OpenCV は日本語のフォルダ名を読めないので、ひな形の `rd()` / `wr()` を使う。
- **背景の跡（いちばん大事）**：部品を抜いた跡は周りの色で埋めるが、ボヤけたシミになる。**大きな跡が丸見えになる動きはしない。**
  - ふきだしは背景に残したまま、上の部品を弾ませる（1→1.1→1）。1より小さくすると元の絵と二重に見える。
  - キャラ・ボールの移動は小さく（数px〜十数px、回転は数度）。大きく動かしたいときは、カメラを動かして「動いたように見せる」（3話2コマ目のジャンプ、1コマ目のシュート）。
  - キャラが画面いっぱいのコマは切り抜けない。絵ごと寄せて揺らす（3話3コマ目）。
  - 跡が見えるのは、ピカッと光る・カメラで隠すなど、一瞬にとどめる（2話2コマ目のキック前）。
- **index.html は手で書く**（build_episode.py は使わない）。お手本の `pin()`（ささえる点）・`cam()`（カメラ）・`bounce()`（弾む）・`shake()`（揺らす）・`swap()`（コマの入れかわり）をそのまま使い、時間は声の長さ（`voice\voices_meta.json`）から決める。
- **写真チェック**：`npx hyperframes snapshot --describe false --no-end --at <秒,...>`。**`--describe false` を必ずつける**（つけないと画像がGoogleのGeminiに送られる）。ふきだしが切れていないか、跡のボヤけが目立たないかを見る。
- 書き出し：`npx hyperframes render -o <N>話_切り抜き版_試作.mp4`。

## 注意

- BGMは無し（無料で使える曲を取ってくる道具はHeyGenのログインが必要なため）。つけたいと言われたら、社長が用意した曲ファイルを `<audio>` で入れる。
- 字幕は画面の 1400px あたり。下の方はリールのボタンや説明文にかぶるので空けてある。
- 声が機械っぽいのは無料の道具の限界。もっと自然にしたいと言われたら HeyGen（月10分まで無料・要ログイン）を提案する。
